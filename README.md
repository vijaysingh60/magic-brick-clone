# 🏠 MagicBricks Clone

A simplified real estate listing platform built with the **MERN stack (MongoDB, Express, React, Node.js)**. This clone allows users to view properties and lets admins manage listings via an admin panel.

---

## 🔧 Tech Stack

- **Frontend:** React.js + TailwindCSS
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Authentication:** JWT-based

---

## 📦 Features

- 🏠 Home Page – List all available properties
- 📝 Property Detail Page – View full details of a property
- 🔐 Admin Panel – Add, edit, or delete properties
- 👤 User Authentication – Login & Signup with role-based access
